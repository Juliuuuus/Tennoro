# Tennoro FR / EN

The site remains static and compatible with GitHub Pages. Generated HTML includes translated content and SEO without requiring JavaScript for indexing.

## Editing

- `templates/*.html`: shared layout and translation tokens.
- `fr.json` / `en.json`: static copy, accessibility labels and metadata (matching keys).
- `messages.mjs`: dynamic UI translations and known API reason translations.
- `routes.mjs`: canonical routes and legacy aliases.
- `runtime.js`: formatting and language preference; `languages.css`: compact navbar selector.

After editing sources, run from the repository root:

```sh
node scripts/build-i18n.mjs
node --test tests/*.test.mjs
```

Commit the generated `fr/`, `en/`, entry-point HTML, catalogs and sitemap alongside sources. Do not edit generated HTML directly. No build service or extra dependency is needed on GitHub Pages.

## Navigation

`/` and old unprefixed routes use a client-side redirect (not an HTTP 301). A saved `tennoro-language` choice takes precedence over browser language; French browsers default to French, all others to English. Direct localized URLs never override the requested language. Manual switches preserve the page, query and hash. Without JavaScript, entry pages provide real FR/EN links.

Canonical content uses `/fr/` and `/en/`, including `dailypick/`, `stats/`, `cgu.html`, `cgv.html` and `confidentialite.html`. The sitemap contains 12 pages with reciprocal language alternates. Old `daily-pick/`, `pronostics-tennis/` and `stats.html` routes remain entry points.

## Local verification

The standalone `carsoccer/index.html` campaign entry redirects straight to `/en/?utm_source=carsoccer&utm_medium=display&utm_campaign=carsoccer_launch`, without reading or changing language preferences. GitHub Pages resolves `/carsoccer` to the directory entry (potentially normalizing to `/carsoccer/` first). It uses an immediate inline redirect plus a zero-delay meta-refresh fallback, with no visible intermediate content. This is not a server-side 301. It is intentionally excluded from the sitemap and is not regenerated by the i18n build. UTM tags identify the campaign for an analytics tool when one is configured; the redirect does not install tracking.

Serve the repository root, for example `python -m http.server 3000 --bind 127.0.0.1`, then open `/fr/` or `/en/`. The live API configuration is unchanged. `?demo=1` remains restricted to loopback hosts and never supplies production fallback data.

API values and player names are not translated. Recognized French reason formats are translated while preserving their values; unknown reasons are omitted in English and a localized unavailable message is shown if no supported reasons remain. Prefer structured multilingual reasons from the backend in future. Legal translations preserve the existing French content and dates; they are not a legal review.
